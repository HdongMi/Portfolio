03 — Projects

실패에서 시작해
수익을 내는 앱까지

Kotlin으로 공공데이터포털 API를 활용한 첫 앱을 만들고, 그 경험을 발판 삼아 교통 앱 시리즈를 키워 수익화에 성공했습니다. 지금은 해외 시장까지 넓혀 가고 있습니다.

개발 프로세스 01 교통 앱 시리즈 02 글로벌 게임 앱

성장 스토리

STEP 1 · 도전

어디역? — 첫 번째 앱

트래픽이 많은 공공데이터 API를 다뤄보기 위해 연습 삼아 만든 지하철 앱
  • 수익화에는 실패했지만, 실시간 공공 API 연동과 앱 출시·운영 전 과정을 처음부터 끝까지 경험했습니다.
STEP 2 · 확장

버스타GO — 고트래픽 실시간 서비스

첫 앱의 경험을 바탕으로 더 많은 사용자가 찾는 실시간 버스 정보 앱으로 확장
  • 설치 수를 늘리며 다음 앱들을 알릴 수 있는 사용자 기반을 만들었습니다.
STEP 3 · 수익화

고속버스 · 공항버스 시간표

버스타GO를 발판으로 출시한 후속 앱들
  • 수익 전환에 성공했고, 개발하는 기쁨과 재미를 느끼며 더 넓은 방향으로 계속 개발하고 있습니다.

Development Process

01 기획·디자인
화면 기획과 UI 디자인
사용자 흐름과 화면 구성을 먼저 설계하고 디자인을 완성합니다.
Figma
02 에셋 제작
앱 아이콘 · 스토어 홍보 이미지
플레이스토어에 노출될 아이콘과 홍보 이미지를 AI로 빠르게 제작합니다.
ChatGPT
03 구조 설계
앱 기초 뼈대 작성
AI와 함께 Kotlin으로 화면 구조와 기본 코드 뼈대를 잡습니다.
Claude · Kotlin
04 데이터 연동
공공데이터 API 연결
공공데이터포털 API를 앱 뼈대에 연결해 실시간 정보를 불러옵니다.
공공데이터포털
05 기능 구현
세부 기능 개발
AI를 활용해 기능을 빠르게 구현하고 완성도를 높입니다.
Claude · Kotlin
06 검수
직접 디버깅 · 반복 검수
AI가 만든 코드를 그대로 쓰지 않고, 직접 테스트하며 문제를 찾아 고치는 검수 과정을 출시 전까지 반복합니다.
직접 수행

AI로 속도를 높이되, 품질에 대한 최종 판단과 책임은 직접 집니다. 이 과정을 반복해 앱을 꾸준히 출시하고 있습니다.
